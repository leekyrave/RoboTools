Robotools is a universal assistant for the administration of the Arizona RP project in GTA SAMP.

 Executable file: Robo_Tools.lua
 Libraries and resources: lib/, resource/
 API: api/apiTools/

 The script contains the following functions:
 Library Manager
 Statistics
 Checkers
 Forms
 Cheats
 Surveillance
 Accompanying administrative functions that simplify the work of the administration

 Settings:
 Interface settings
 Checker settings and displaying them on the user’s screen
 Custom chat settings
 Admin cheat settings
 Form settings, acceptance of admin forms for issuing punishments
 Personal binds and hotkeys
 Warnings for violations occurring on the server
 Events menu

 There is a binding in the script, but it is quite easy to disable it by commenting out the binding checking functions.
 Activation - /rmenu /mmenu /tmenu (Modifiable)


 In addition, this repository contains the direct part of the API

 api/ - api for the site
 apiTools/ - api for tools

 The API was used to collect some information from the application and pass it to the application.
 For example: Update Manager, administration statistics, namely its transfer from the game through Requests from the application.

 GEOIP, system of similar reports, etc.
